# Sistema de Agendamento de Pacientes

Sistema web desenvolvido para cadastro e gerenciamento de consultas de pacientes.

## Descrição

Este projeto permite registrar pacientes, definir datas e horários de consultas e visualizar os agendamentos realizados. Os dados são armazenados localmente no navegador utilizando LocalStorage.

## Funcionalidades

* Cadastro de pacientes
* Registro de telefone
* Agendamento de consultas
* Listagem de consultas agendadas
* Exclusão de consultas
* Armazenamento local dos dados
* Interface responsiva

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* LocalStorage

## Como Executar

1. Faça o download dos arquivos do projeto.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.
4. Preencha os dados do paciente.
5. Clique em "Agendar Consulta".

## Armazenamento de Dados

As informações das consultas são armazenadas no navegador utilizando LocalStorage. Dessa forma, os dados permanecem salvos mesmo após fechar ou atualizar a página.
